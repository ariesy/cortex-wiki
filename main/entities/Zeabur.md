# Zeabur

面向开发者的应用部署平台，强调简单易用与多语言支持，RSSHub 官方支持的部署选项之一。

## RSSHub 部署要点

- 在 RSSHub 部署页点击 "Sign up for Zeabur" 直接进入部署流程，支持零配置部署。
- 支持自定义域名绑定，官方提供 domain-binding 文档（`https://docs.zeabur.com/deploy/domain-binding`）。

## 核心特性

- **一键 / 低配置部署**：连接 Git 仓库或直接部署，无需复杂服务器配置。
- **多语言 / 多运行时支持**：Node.js、Python、Go、静态站等开箱即用。
- **自定义域名绑定**：可绑定自有域名，文档完善。
- **Serverless / 容器化**：按需自动扩缩，计费灵活。
