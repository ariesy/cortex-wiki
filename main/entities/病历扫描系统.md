# 病历扫描系统

对病历文件做增量扫描并向量入库的系统。

## 运行方式

- **扫描类型**：增量扫描
- **触发方式**：命令行 / cli（均为手动或定时触发，非事件驱动）
- **典型执行时间**：每日 08:00 左右

## 性能基线（2026-04-29）

| 指标 | 数值 |
|------|------|
| 扫描文件 | 444 个 |
| 新增文件 | 0 |
| 修改文件 | 0 |
| 跳过文件 | 0 |
| 失败文件 | 0 |
| 向量入库 | 0 |
| **耗时** | **4 分 6 秒** |

一次全成功的增量扫描，约 **444 文件 / 4 分钟**。可作为后续判断扫描是否异常的基线——若耗时显著变长或出现失败文件，需排查。

## 报告格式

扫描完成后输出统计：总文件数、新增/修改数量，以及各阶段处理情况。
