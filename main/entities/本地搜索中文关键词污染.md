# 本地搜索中文关键词污染

本地 SearXNG 元搜索在做**中文行业/地域调研**时，结果被同名词、谐音词和旅游内容系统性污染，属于可复现的检索失败模式。

## 典型症状

| 关键词 | 实际返回 |
|--------|---------|
| 风电 | 「豆包」（字节跳动 AI）内容 |
| wind | Wind 金融终端 / 抖音 |
| 郴州 风电 | 郴州旅游、地理百科 |
| site:gov.cn 限定 | 政府站编码错误，抓取乱码 |

## 已验证无效的尝试

- 中英文双语切换
- 多关键词组合（市级 → 县级 → 省级）
- `gov.cn` 站点限定
- 直接抓取市发改委 / 市政府网站

## 有效缓解

1. 放弃「地名 + 细分行业」，改为「上级行政区 + 行业整体」（如湖南风电而非郴州风电）取背景数据。
2. 转向行业数据库 / 省级统计年鉴类页面。
3. 报告中显式声明数据缺口（如「全市装机总量暂缺，以下为定性分析」），避免拿污染结果充当事实。

## 影响

做中文产业调研（尤其是三四线城市 + 细分行业）时，不要假设本地搜索能拿到精确统计数据；应提前把「数据不可得」写进结论，或直接改用付费/官方数据源。
