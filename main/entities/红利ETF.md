## 指数编制规则（2023-12版V1.3）

- **选样**：中证全指中过去三年连续现金分红、股利支付率均值>0且<1的股票，按三年平均现金股息率排序取前100只
- **加权**：股息率加权（派许公式），与市值加权完全不同
- **调仓**：每年1次（12月第二个周五下一交易日），调整比例一般≤20%（2024/2025年均为20进20出）
- **约束**：单股权重≤10%；总市值<100亿者权重≤0.5%；**无行业限制**
- **基日/基点**：2004-12-31/1000点，2008-05-26发布

## 投资逻辑

**核心逻辑：** 规则化的高股息组合——"只买分红最慷慨的100家公司、每年12月按股息率高低强制换手20%、让分红率最高的股票自动变重"。三重自平衡机制：股息率加权天然高抛低吸、年度调仓剔弱纳强、100只分散单股风险。

**核心看点：**
1. 股息率4.15% vs 10Y国债1.71%，利差2.44pct，低利率+资产荒下的稀缺现金流资产
2. 新国九条分红制度化：2025年全A 3,765家公司分红2.52万亿元（+3.32%），分红比例46.79%
3. 险资/中长期资金入市（FVOCI偏好高股息），跟踪中证红利ETF合计规模约337亿元
4. 历史全收益年化约11.5-12.6%，股息贡献3.8-4.3pct；任何5年周期仅1/16为负

**结构性观察（与市场印象相反）：**
- 前十大权重19.19%中**能源占7席、银行0席**（银行虽为第一大行业22%，但股息率加权稀释了市值巨无霸）
- 银行+煤炭+交运合计约52-53%，**"金融+周期"主导**；公用事业仅0.4%（长江电力2024-12已调出）
- 2026年7月指数大涨11.09%（上半年-8.75%后反弹），YTD(至7-30)+1.37%价格口径

## 估值判断（2026-08-03，四大师框架）

- **股息率4.08-4.15% = 近10年最低（分位0.14%）**，安全垫最薄；均值5.24%、历史区间4.08-6.89%
- PE分位97.93%的**本质是盈利周期底部**（煤价/集运/银行息差压缩使E下滑），非股价泡沫；PB 0.85破净更干净
- 三情景(1年)：悲观30% → -11%~-16%（股息率回归均值5.24%对应指数约4,395点/-20.8%）；中性45% → +2%~+9%；乐观25% → +14%~+19%；概率加权约+2%~+5%，**当前是"防御+现金流"工具，不是"高回报"工具**
- **最大风险（芒格反面思考）**：股息率均值回归通过"价格下跌"实现 + 周期股盈利塌方让"高股息"现出原形（2007-2008高股息陷阱）+ 风格切换持续（2026上半年红利回撤17%已真实演绎）

## 配置策略（2026-08-03）

| 情形 | 建议 |
|------|------|
| 空仓者 | 不急于追高。等股息率≥4.8%（指数约4,800-5,000点）或回调至5,000点附近建底仓；或先≤1/3目标仓位小额建仓，随股息率抬升分批加 |
| 持仓者 | 持有为主（季度现金分红+100只分散）；已达目标仓位不再加；股息率跌破3.8%减仓 |
| 卖出信号 | 股息率<3.8%（估值透支）；成分股分红总额连续两年负增长；利率大幅上行；风格长期转向成长且红利跑输3年以上 |
| 加仓信号 | 股息率回升至5%以上；煤炭/银行盈利见底回升；指数回到5,000点下方 |

**适合**：需要稳定现金流的退休/年金型；能忍受单年>17%回撤的长期价值型；组合5-15%防御仓位。
**不适合**：追求高增长的成长型；短期交易者；无法承受25%以上回撤的保守者。

## 2026-06-25 群聊因子对比研究更新

**与 300价值ETF 的核心差异**：
- **选样范围**：300价值只能在沪深300的300只大盘股里选；中证红利是全A选股，因此纳入中盘红利股（煤炭、公路、港口、区域银行、运营商等）
- **行业分布**：300价值银行独大（45-55%），中证红利银行仅25-30%，行业更分散
- **风格本质**：300价值 = "估值修复型价值"；中证红利 = "现金流收入型价值"（买收租物业拿分红）

**与 红利低波100 的核心差异**：
- 红利低波100 = 中证红利 + 过去一年日波动率过滤（取波动率最低的100只）
- 红利低波100 持有体验更好（2022-2024 三年正收益），但当前 PE 分位60-70% 也已不便宜
