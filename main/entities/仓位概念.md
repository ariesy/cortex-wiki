# 股票仓位（Position）概念与用户用法

回答用户仓位相关问题时需区分**两个维度**，并结合其价值投资风格作答。

## 基本定义

**仓位 = 持有某只股票的市值 ÷ 账户总资金**

账户 100 万，买入 50 万股票 → 仓位 50%。

## 两个维度（最易混淆点）

| 维度 | 算法 | 用途 |
|---|---|---|
| **个股仓位** | 单只股票市值 ÷ 总资金 | 控单一股票风险暴露，防暴跌 |
| **整体仓位** | 所有股票市值 ÷ 总资金 | 反映满仓/空仓，决定整体敞口与应对能力 |

例：账户 100 万，腾讯 30 万 + 苹果 20 万
- 腾讯仓位 30%、苹果仓位 20%（个股维度）
- 整体仓位 50%，另 50 万现金（整体维度）

### 口语理解技巧

| 说法 | 通常指 |
|---|---|
| 「现在仓位很重」 | 整体仓位高 |
| 「腾讯仓位太重了」 | 单只股票占比过高 |
| 「减仓到五成」 | 整体仓位降到 50% |
| 「单只股票不超过 10%」 | 风控规则，个股上限 |

## 常用术语

| 术语 | 含义 |
|---|---|
| 空仓 | 无持仓，100% 现金 |
| 轻仓 | 通常 30% 以下 |
| 半仓 | 约 50% |
| 重仓 | 70%–80% |
| 满仓/全仓 | 接近 100% |
| 加仓 / 减仓 | 增加 / 降低仓位 |
| 建仓 | 首次买入某只股票 |
| 清仓 | 全部卖出，持仓归零 |

## 为什么重要

1. **控制风险** — 满仓跌 20% 和半仓跌 20% 损失完全不同
2. **心态管理** — 重仓波动大，容易心态失衡做出错误决策
3. **应对机会** — 熊市末期需要现金抄底，空仓才有买入能力

## 用户视角（价值投资 / 长期持有）

用户风格是价值投资、长期持有，不频繁加减仓，更关注基本面。因此：

- 仓位对他更接近**大类资产配置**（A股 / 港股 / 美股各占多少）
- 个股仓位主要由**买入成本和基本面变化**决定，不是短线交易层面的管理
- 回答时应往配置层面引导，而非短线择时
