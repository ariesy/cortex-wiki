# 天翼云盘无法备份映射网络驱动器

天翼云盘客户端只认本地真实路径，`Z:\` 这类映射盘不被当作可备份目录。

## 核心原因

- 客户端按「本地真实磁盘」路径监控文件变动
- 映射盘本质是网络会话（UNC `\\server\share`），不是本地卷
- file watcher 对网络驱动器往往失效，增量同步/实时备份不可靠
- 部分版本根本不把映射盘列为可选备份目录

## 可行方案（按推荐度）

| 方案 | 做法 | 评价 |
|------|------|------|
| ①目录挂载 | 用 `mklink /D` 把网络共享伪装成本地文件夹，再设为备份目录 | 「目录挂载」正解 |
| ②Robocopy + 本地中转 | `robocopy "\\server\share\folder" "D:\TianyiBackup\folder" /MIR /R:2 /W:5` + 任务计划程序，天翼云盘只备份 `D:\TianyiBackup` | 最稳妥、准实时 |
| ③本地中转目录 | 客户端自动备份指向真实本地路径，用 ② 灌数据 | ② 的变体 |
| ④手动拖拽 | 拖到本地后再上传 | 仅应急，不适合持续备份 |

**推荐**：② Robocopy 镜像 + 本地中转 + 天翼云盘备份本地目录，完全绕开映射盘不被识别的问题。

## 待确认

- 备份目标是「异地容灾」还是把天翼云盘当主存储，会影响方案细节（源端 NAS/SMB 类型、是否要求实时）。
