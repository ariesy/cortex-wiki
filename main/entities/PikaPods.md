# PikaPods

托管开源应用的平台，提供现成的一键部署模板，RSSHub 官方支持的部署选项之一。

## RSSHub 部署要点

- RSSHub 部署页将 PikaPods 列为独立部署选项，通过现成模板一键部署，几乎零配置。
- 适合不想自己维护 Docker / 服务器、只想快速跑起 RSSHub 的用户。

## 核心特性

- **开源应用市场**：提供大量开源项目的托管实例，如 RSSHub、Nextcloud、Gitea 等。
- **一键部署**：模板化部署，无需编写 Dockerfile 或 YAML。
- **托管运维**：更新、备份、监控由平台负责，省心。
- **按订阅 / 实例计费**：以固定月费方式托管实例，价格透明。
