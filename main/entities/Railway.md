# Railway

现代化应用托管平台，强调秒级部署与基础设施即代码，RSSHub 官方支持的部署选项之一。

## RSSHub 部署要点

- RSSHub 部署页将 Railway 列为独立部署选项，支持连接仓库或模板一键部署。
- 按需自动扩缩容，适合小型抓取服务低负载运行。

## 核心特性

- **秒级部署**：连接 GitHub 仓库或使用模板，几十秒内完成部署。
- **声明式基础设施**：通过 config / Nixpacks 自动识别语言与构建方式。
- **按量计费**：按使用量（CPU / 内存 / 网络）计费，低流量项目成本可控。
- **内置数据库 / 服务**：Postgres、Redis 等可一键附加。
