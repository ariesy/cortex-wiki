# 投资偏好与风格（朱琨）

2026-05-05 通过每日问答补充确认的一组投资偏好，可作为仓位建议、市场对比、推送风格的默认参照。

## 核心结论

| 维度 | 偏好 |
|------|------|
| 优先加仓市场 | **港股**（科技估值洼地、弹性大） |
| 风险观 | **保持流动性冗余**，为不可预见的极端情况留 buffer |
| 持仓风格 | **长期持有 + 价值投资底色**，少择时、忽略短期波动 |
| 调整方式 | 随**基本面变化灵活调整**，不设硬性止损 |
| 地域优势 | **深圳**：信息密度高、从业者交流多，信息差即护城河 |
| 沟通方式 | 重大决策**简单告知、不深入讨论**，专业事交给专业的人 |

## 使用提示

- 给加仓建议时默认把港股放在对比序列首位。
- 不主动推荐满仓或高杠杆方案——流动性冗余是明确偏好。
- 汇报重大决策时给结论即可，避免长篇论证或反复追问确认。
