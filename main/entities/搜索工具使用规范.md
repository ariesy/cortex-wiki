# 搜索工具使用规范

## 1. 调研任务强制流程（superresearch）

**触发关键词**：调研、research、研究、调查、分析、对比、评估

强制 5 阶段：

```
Phase 1 (Brief) → Phase 2 (Plan) → Phase 3 (Research) → Phase 4 (QA) → Phase 5 (Deliver)
```

- ❌ 禁止：直接搜索、直接回答、直接给数据
- ✅ Phase 1 完成前不进行任何数据收集
- ✅ Phase 2 完成前不开始执行
- ✅ 违反流程时必须立即承认并补上缺失阶段

## 2. local-web-search（自建搜索引擎）

- **路径**：`~/.openclaw/workspace/skills/local-web-search`
- **命令**：
  ```
  python3 ~/.openclaw/workspace/skills/local-web-search/scripts/search_local_web.py --query "<query>" --limit 5
  ```
- 基于 **SearXNG + Scrapling** 反爬引擎，多引擎并行（Bing / DuckDuckGo / Google / Startpage / Qwant）
- 服务不可用时先启动：`./start_local_search.sh`

## 3. Skills 搜索优先级

1. **GitHub awesome-openclaw-skills** — 首选
2. **ClawHub (clawhub.com)** — 次选
3. 其他网络公开渠道 — 仅前两项找不到时使用

返回格式必须包含：**来源、功能简介、成熟度评价、安全性评价**（⚠️ 安全性为必填项）。

## 4. Context Hub (chub)

用于获取 API 文档，**优先于 web_search**：

1. 优先查文档再写代码 — `chub get <id>`
2. 查不到时再搜网页 — `chub search` 找不到才用 web_search
3. 重要发现要注释 — `chub annotate <id> <注释>`

## 5. web_search / web_fetch

OpenClaw 内置搜索/抓取工具，用于一般性网络信息获取，按默认行为使用。

## 6. OpenClaw 文档查询优先级

1. 本地文档 `/home/linuxbrew/.linuxbrew/lib/node_modules/openclaw/docs`
2. GitHub 源码
3. web_search
