## 综合决策（2026-08-03）
- **结论：观望为主，29–30 元以下分批建仓；8月20日中报为第一检验点**
- 空仓者：<30 元（PB<0.89x）分批建仓，或等中报确认个贷不良与息差企稳后再动手，不建议现价一次性重仓
- 持仓者：持有不加仓，紧盯①核心一级资本充足率能否止跌回稳（目标≥9.5%）②个贷不良率≤2% ③新管理层风控风格
- 卖出信号：个贷不良连续两季>2.5% / 核心一级跌破8.5%且无再融资 / 激进规模扩张 / 股价>38元
- 加仓信号：股价回 29–30 元且基本面未恶化 / 息差连续两季环比回升 / 中报验证转型逻辑 / 大股东增持
