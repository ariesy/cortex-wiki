# 南网科技 (688248.SH)

## 基本信息

- **公司全称**：南方电网电力科技股份有限公司
- **证券代码**：688248.SH（科创板）
- **实际控制人**：国务院国资委（南方电网100%控股）
- **所属行业**：电力设备 > 储能/电力电子/智能配用电
- **核心业务**：四大板块（**新型储能 / 配用电设备 / 检测 / 运检**）
- **上市日期**：2021年12月22日，发行价12.24元
- **核心定位**：**南方电网旗下唯一科技型上市平台**
- **员工人数**：919人（2024年）
- **总市值**：约 234 亿元（2026-07-24）
- **总股本**：5.647 亿股
- **收盘价**：**41.52 元**（2026-07-24）

- **股息率**：0.44%（2025年）

## 算电协同业务定位（核心主线一：算电协同基建）

**战略地位**：**算电协同战略下"电网国家队"，确定性最高的标的之一**

### 四大核心业务（2025年营收均近10亿元）

#### 1. 构网型储能 ⭐⭐⭐⭐⭐
- **技术突破**：在全运会开幕式上，构网型储能系统**取代传统柴油发电机**完成保供电（全球首例）
- **战略价值**：解决西部弱电网接入，独立构建电压与频率支撑
- **AIDC配储刚需**：从"可选项"→"必选项"
- 公司**全球首例**柴油机替代案例，技术领先

#### 2. SST（固态变压器）⭐⭐⭐⭐⭐
- **技术指标**：220kV直转800V，全链路效率**98.5%**
- **应用场景**：算力中心高压直入、中压直转、直流直供
- **历史积累**：2017年牵头完成国家级重点研发计划；2020年东莞安华数据中心落地**国内首个**兆瓦级电力电子变压器
- **合同累计**：电能路由器、柔性互联装置等**累计合同超5亿元**

#### 3. 配用电设备
- 服务"源网荷储一体化"
- 配合 AIDC 配储

#### 4. 检测+运检
- 智能电网检测服务
- 电网运维（南方电网背书）

### 2025年研发投入
- **约2.4亿元**（占营收6.5%）
- 重点方向：构网型储能、碳化硅电力电子、具身智能、丝路OS
- **机器视觉领域获国家专利金奖**
