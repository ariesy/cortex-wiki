# Sealos

基于 Kubernetes 的云操作系统，主打"按需付费的云开发平台"，RSSHub 官方支持的部署选项之一。

## RSSHub 部署要点

- RSSHub 部署页将 Sealos 列为独立部署选项，可一键部署到 Kubernetes 集群。
- 采用 Serverless 容器 / 应用托管模型，按使用量计费。

## 核心特性

- **云操作系统**：以 Kubernetes 为底座，提供应用商店、数据库、存储等一体化服务。
- **一键部署**：通过应用模板 / 商店快速拉起 RSSHub 等服务。
- **按量计费**：按 CPU / 内存 / 流量使用计费，适合低负载个人服务。
- **国产开源**：由国内团队打造，中文文档完善，国内访问友好。
