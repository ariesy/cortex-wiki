- 🕸️ **The orchestrator** — 在 durable graphs 上跑 agent 舰队
- 🔬 **The deep researcher & doer** — 在你问完之前就扫完你的数据和网页

## 存疑点（confidence 标为 medium-high 的原因）

2. Early Beta 阶段，README 描述的 brain / orchestrator / deep researcher 三大能力的**实际完成度未经验证**
3. 商标风险："OpenHuman" 与已存在的 Open Humans Foundation / openhumans 项目同名，需留意
