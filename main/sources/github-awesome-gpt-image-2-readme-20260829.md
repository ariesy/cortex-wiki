## 定位（原文）

副标题：「Prompt as Code | GPT-Image2 Industrial Prompt Engine & Template Library, 500+ Reverse-Engineered Cases, 20+ Industrial Templates」

项目愿景（原文大意）：GPT-Image2 普及后，AI 出图的问题从"能不能生成"变成"能不能稳定、可控、可复用地产出"。本项目把社区零散案例转成 **Prompt-as-Code 资产**，便于 agent 与自动化工作流复用。

## 关键事实

- 核心方法：**把散文式 prompt 压缩成结构化协议**
- 🧱 Atomic schema：把主体、布光、材质、版式、视觉细节拆成**可组合**的部分
- ⚙️ Workflow friendly：为 agent / 脚本 / 自动化系统设计
- 🧬 Structured control：提升版式、文案、信息层级的**可控性**
- 案例规模：README badge 显示 **544 cases**（项目标题写 500+；主人转述为 530+，口径不一，以 badge 544 为最新）
- 模板：20+ 套工业级模板
- 配套站点：gpt-image2.canghe.ai（可视浏览、复制完整 prompt、按风格/场景筛选、Google 登录后试生成、跳回 GitHub 源案例）
- **内含 Agent Skill**：`gpt-image-2-style-library`，从站点同一份数据里选风格/模板/分类/场景标签
